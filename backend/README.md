# SmartHospital

SmartHospital is a web-based hospital management system designed to make hospital services easier and more organized.

## Features

- Patient Management
- Doctor Management
- Appointment Management
- Hospital Roadmap
- Backend API
- User-Friendly Interface

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- PostgreSQL

## Project Structure

- backend – Backend/API files
- frontend – Frontend website files
