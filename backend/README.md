# SmartHospital

SmartHospital is a web-based hospital management system designed to make hospital services easier and more organized.

## Features

- Patient Management
- Doctor Management
- Appointment Management
- Hospital Roadmap
- Backend API
- User-Friendly Interface

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- PostgreSQL

## Project Structure

- `backend` – Backend and API files
- `frontend` – Website interface
- `README.md` – Project information
